# ABYSS RUSH — 海底グランプリ

`#/experiments/kart-rush` で遊べる、オリジナルのブラウザ内完結型カートレース。
1コース約1.72km・3周・プレイヤー1台＋AI5台。サンゴ礁、ウミガメ、沈没船、クラゲの洞窟、クジラ、浅瀬への帰還の6区間をつなぐ透明トンネルを走る。

## 操作

- 左右矢印 / A・D：ハンドル
- 上下矢印 / W・S：アクセル・ブレーキ（自動アクセルONが標準）
- SPACE / SHIFT：ドリフト。ゲージが45%以上になったら離して加速
- E / アイテム欄：ターボ、ソナーパルス、バブルシールド
- ESC：一時停止・再開。フォーカスを失った場合も自動で一時停止
- タッチ端末：左右ボタン、DRIFT、BRAKE、アイテム欄。自動アクセルOFF時はACCELも表示
- 音声は初期OFF。音ボタンを押した場合のみWeb Audioを開始

## 構成

- `track.ts`：閉じたスプラインを距離でサンプリング。全長・路幅・海域・配色を定義
- `engine.ts`：DOM非依存の60Hz固定刻みシミュレーション、順位、周回、車両衝突、AI、アイテム
- `scene.ts`：Three.js描画、透明トンネル、路面、追従カメラ、リソース解放
- `models.ts` / `scenery.ts`：外部画像・モデルに依存しない車両と海洋生物
- `use-race.ts`：入力・可視性・描画ライフサイクル。React UIの更新は約10Hz
- `RaceHud.tsx` / `RaceMenus.tsx`：レースHUD、ミニマップ、操作パッド、設定、結果
- `sound.ts`：ユーザー操作後に有効化する合成エンジン音・効果音

走行はコース沿いの距離＋横方向位置によるアーケードモデル。前進距離は連続・単調で、スタート前のグリッド位置は負の距離となる。逆走やゴール線の往復で周回数を増やせず、路外ショートカットもない。ガードレールは減速と押し戻しで処理する。
AIも同じ車両計算を使い、先読みしたカーブ・前方車・目標走行ラインからハンドルとアクセルを決定する。テスト時に再現できるよう乱数は固定シード。難易度は主に目標速度を変更する。プレイヤーの完走後も残りのAIが走り、結果に完走タイムを追記する。

## 検証

- `npm run test:kart-rush`：コース連続性、カウントダウン、一時停止、制動、ドリフト、路外復帰、アイテム、周回境界での命中、全車3周完走、難易度と再現性を検証
- `npm run build`：既存のCandleCore準備、TypeScript、Viteビルド
- Playwright環境の用意後：`npx playwright test tests/browser/kart-rush.spec.ts`
- レースE2Eは1440×900、1024×768、390×844、844×390と明暗の表示設定を対象にする

## 表示と性能

軽量表示は描画解像度・魚群数を減らし、海底の光の揺らぎを省く。モバイルは横画面を推奨するが、縦画面でも操作できる。3D描画の失敗・WebGLコンテキスト消失時には再試行画面を表示する。

このゲームは簡易モデルによるアーケード作品。トンネルのガラスは低不透明度、クジラの影は簡易投影。オンライン対戦、車種選択、ジャンプ、分岐コースは含まない。実機iPad Safariでのフレームレートとタッチ感触は、公開後の実機確認が必要。
